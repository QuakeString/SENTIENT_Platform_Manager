What changes from 0.9.1
  • Windows Setup gets the choice of where SENTIENT runs, like Linux. Default and recommended: On this computer.
  • On Windows, ClickHouse always runs in Docker inside WSL 2, also with On this computer (as today). Its card says Service + WSL 2.
  • WSL 2 not on: In Docker stays selectable; Setup turns it on, Windows restarts once, Setup continues after sign-in.
  • No virtualization: In Docker and ClickHouse are greyed, with the reason on the card and what to do behind the (i).
  • Linux: On this computer becomes the default too (today Docker is preselected there).
