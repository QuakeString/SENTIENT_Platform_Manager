Setup guide inside the Platform Manager

Setup guide no longer opens the website. It opens the steps inside the Add a remote instance dialog, for the system you picked, and includes how to make an SSH key.

How it works
  • G1 (recommended): Setup guide widens the dialog and shows the steps on the right, so the form stays in view while you follow them. Pressing it again, or the close button, folds the guide away. Switching System between Linux and Windows switches the guide too.
  • G2: the guide opens as its own dialog over the form, with its own Linux and Windows switch. Close returns to the form as you left it.
  • Commands already carry the address, port and user typed in the form (here 192.168.1.20, admin) and a copy button. Each command says where to run it: on this computer or on the server.
  • "This computer" is not a choice in the app: the Platform Manager knows whether it runs on Windows or Linux and shows the matching key commands. The switch above only lets you preview both.
  • The text is the same as the website page "Manage SENTIENT on other computers", plus the new SSH key steps. Nothing opens a browser.
