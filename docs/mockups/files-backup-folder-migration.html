Platform Manager: Files, backup folder, Migration

Mockups for approval. Nothing here is built yet. Each window is drawn at the app's real size (14 px text, 32 px buttons, 12 px cards, 8 px buttons and inputs) on a remote instance, so the bar is that instance's colour.

A. MigrationB. Backup folderC. Files

A. Migration: all three types, the current one marked

The page always lists all three types. The one SENTIENT runs on now is selected and carries a "Current" pill, so you see at a glance which database it is. Pick another and the button names it.

A1OpenedCurrent type selected, button off until another type is picked
A2Another type pickedCurrent pill stays on TimescaleDB; button now says what it does
A3Compose file not ours yetBanner on top, the types still visible but off; after the takeover finishes the page re-reads and the banner is gone

B. Backup folder you can change

The folder is a row on the Backup page with its free space and a Change… button. On a remote instance Change… opens a folder chooser on that server. It checks the folder before it can be picked, and asks what to do with the backups already in the old folder.

B1Backup pageFolder row with free space; quiet saves, no job view
B2Chooser on the serverWritable and free space checked as you move
B3Folder not usableReason in plain words; one button fixes it with the administrator password
B4Backups already in the old folderMove them or leave them; left ones stay listed and restorable
B5After the changeBackups from the old folder keep their place in the list with an "Old folder" pill

C. Files: this computer and the server side by side

A new "Files" item in the menu, after Logs. Left pane is this computer, right pane is the open instance over the same SSH connection. Drag between panes, or Copy and Paste (Ctrl+C, Ctrl+V), folders included. Copies run in the background on the thin bar under the top bar; the chip opens the list with Cancel.

C1BrowsingShortcuts to the SENTIENT folders on the server; owner column on the server side
C2Drag to the serverThe target pane lights up; the count rides with the pointer
C3CopyingThin bar plus chip in the top bar; the transfers list opens from the chip
C4Right clickCopy, Paste, Rename, New folder, Download, Delete
C5File already thereThree short choices, applies to the rest if ticked
C6Root-owned folderRead-only until you open it as administrator

Files: rules behind the mockup

  • Works for this computer too: then the right pane is a second local pane, handy for copying to a USB disk.
  • Transfers use sftp on the existing connection, resume a broken file from where it stopped, and check the size at the end.
  • Delete on the server asks every time. Nothing goes to a recycle bin there, and the dialog says so.
  • Editing a file in place is not part of this; open it with Download, change it, copy it back.
