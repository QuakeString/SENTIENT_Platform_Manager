Platform Manager: Licence

Mockup for approval; nothing is built. A "Licence" page in the menu, for this computer and for every remote instance. Every licence action goes through SENTIENT's own licence functions and needs the SENTIENT system administrator's email and password. The Platform Manager never saves that password.

Rules behind the mockup

  • The page calls SENTIENT's licence functions on the server (over the SSH connection for a remote instance), exactly what the Licence page in SENTIENT does. The licence server sees the same SENTIENT, so hardware binding and the build check are unchanged.
  • Sign-in uses SENTIENT's normal system administrator sign-in, including its lockout after wrong passwords. The session is kept in memory while the page is open and ends on Sign out, on closing the app, or after 15 minutes idle.
  • Activate, Replace, Deactivate and Remove each ask for the password again in their own dialog, so a forgotten open session cannot change the licence. Refresh and reading need only the sign-in.
  • Every change is written to SENTIENT's audit log as that administrator, as it is today from the web page.
  • Open question for you: should each instance tile on the Instances page also show a one-word licence state (Active, ends in N days, Over a limit, None)? That read would happen without the sign-in.
